# 04. Emitter And VDBE Tasks

這一組把 plan 變成 bytecode，再看 bytecode VM 如何 step。讀 `core/vdbe/execute.rs` 時只讀任務指定的 opcode 區塊。

- [ ] T116. **ProgramBuilder basics**: read `core/vdbe/builder.rs`; output how instructions, registers, labels, and cursors are allocated.
- [ ] T117. **Instruction enum map**: read `core/vdbe/insn.rs`; output instruction families: control flow, cursor, record, arithmetic, transaction, aggregate, sorter.
- [ ] T118. **Emitter entrypoint**: read `core/translate/emitter/mod.rs`, `core/translate/emitter/select.rs`; output how a `SelectPlan` starts becoming instructions.
- [ ] T119. **Main loop skeleton**: read `core/translate/main_loop/init.rs`, `core/translate/main_loop/open.rs`, `core/translate/main_loop/body.rs`, `core/translate/main_loop/close.rs`; output the four phases of a scan loop.
- [ ] T120. **Loop conditions**: read `core/translate/main_loop/conditions.rs`; output where WHERE residual predicates become branch instructions.
- [ ] T121. **Seek loop emission**: read `core/translate/main_loop/seek.rs`; output how rowid or index seeks differ from full scans.
- [ ] T122. **ORDER BY emission**: read `core/translate/order_by.rs`, `core/vdbe/sorter.rs`; output when sorter bytecode is needed.
- [ ] T123. **Aggregate emission**: read `core/translate/aggregation.rs`, `core/translate/group_by.rs`; output where `AggStep` and `AggFinal` are emitted.
- [ ] T124. **Expression emission entry**: read `core/translate/expr/emission.rs`, `core/translate/expr/translator.rs`; output how expression AST becomes registers.
- [ ] T125. **Column expression emission**: read `core/translate/expr/columns.rs`; output how a resolved column becomes cursor plus column number plus register.
- [ ] T126. **Binary expression emission**: read `core/translate/expr/binary.rs`; output how arithmetic and comparison emit instructions.
- [ ] T127. **Function expression emission**: read `core/translate/expr/functions.rs`; output how scalar and aggregate function calls diverge.
- [ ] T128. **Condition emission**: read `core/translate/expr/condition.rs`; output how SQL truthiness maps to VM branches.
- [ ] T129. **INSERT emission**: read `core/translate/insert.rs`, `core/vdbe/execute.rs`; output the bytecode path for `MakeRecord`, `NewRowid`, `Insert`.
- [ ] T130. **UPDATE emission**: read `core/translate/update.rs`, `core/translate/emitter/update.rs`; output how old rows, new rows, indexes, and RETURNING are handled.
- [ ] T131. **DELETE emission**: read `core/translate/delete.rs`, `core/translate/emitter/delete.rs`; output how row location and index deletion are coordinated.
- [ ] T132. **DDL emission**: read `core/translate/schema.rs`, `core/translate/alter.rs`; output why DDL is emitted as ordinary VM writes plus schema cookie updates.
- [ ] T133. **Program runtime state**: read `core/vdbe/mod.rs`; output the roles of `Program`, `ProgramState`, registers, cursors, and execution state.
- [ ] T134. **Program::step**: read `core/vdbe/mod.rs`; output how normal execution, explain, and special modes are selected.
- [ ] T135. **normal_step loop**: read `core/vdbe/mod.rs`; output fetch-decode-execute flow and how `pc` moves.
- [ ] T136. **Active opcode state**: read `core/vdbe/mod.rs`; output why long-running opcodes need saved state.
- [ ] T137. **Register model**: read `core/vdbe/mod.rs`, `core/vdbe/value.rs`; output how registers differ from rows and records.
- [ ] T138. **Result rows**: read `core/vdbe/execute.rs`, `core/vdbe/mod.rs`; output how `ResultRow` returns values to `Statement::step`.
- [ ] T139. **Control flow opcodes**: read `op_goto`, `op_jump`, `op_if`, `op_if_not`, `op_once` in `core/vdbe/execute.rs`; output how bytecode branches implement SQL loops.
- [ ] T140. **Arithmetic opcodes**: read arithmetic functions in `core/vdbe/execute.rs`; output how NULL, integer, float, and overflow cases are handled.
- [ ] T141. **Comparison opcodes**: read `op_compare`, `op_comparison`, collation helpers in `core/vdbe/execute.rs`; output how ordering and collation affect branching.
- [ ] T142. **OpenRead/OpenWrite**: read `op_open_read`, `op_open_write` in `core/vdbe/execute.rs`; output how root pages become cursors.
- [ ] T143. **Column opcode**: read `op_column` and `op_column_fetch` in `core/vdbe/execute.rs`; output fast path, slow path, and IO yield path.
- [ ] T144. **Rowid opcodes**: read `op_row_id`, `op_new_rowid`, `op_idx_row_id`; output how table rowid and index payload rowid differ.
- [ ] T145. **Seek opcodes**: read `op_seek`, `seek_internal`, `op_seek_rowid`; output how VM asks storage to position a cursor.
- [ ] T146. **Next and Prev**: read `op_next`, `op_prev`; output how cursor movement, branch target, and EOF interact.
- [ ] T147. **Record opcodes**: read `op_make_record`, `op_row_data`; output how register values become encoded records and back.
- [ ] T148. **Insert and Delete opcodes**: read `op_insert`, `op_delete`, `op_idx_insert`, `op_idx_delete`; output storage mutations and saved opcode states.
- [ ] T149. **Transaction opcodes**: read `op_transaction`, `op_auto_commit`, `op_savepoint`; output where VDBE crosses into pager and WAL.
- [ ] T150. **Aggregate opcodes**: read `op_agg_step`, `op_agg_final`; output how accumulators live in registers.
- [ ] T151. **Sorter opcodes**: read sorter opcodes in `core/vdbe/execute.rs`, `core/vdbe/sorter.rs`; output how ORDER BY and GROUP BY use temporary storage.
- [ ] T152. **RowSet opcodes**: read `core/vdbe/rowset.rs`, rowset opcodes; output why UPDATE/DELETE need rowid sets.
- [ ] T153. **Subprogram opcodes**: read `op_program`, coroutine opcodes, trigger execution code; output how trigger/subquery execution nests programs.
- [ ] T154. **EXPLAIN engine**: read `core/vdbe/explain.rs`; output how bytecode becomes human-readable rows.
- [ ] T155. **VDBE milestone**: choose one `EXPLAIN` output and annotate every instruction with compiler source and runtime opcode source.
