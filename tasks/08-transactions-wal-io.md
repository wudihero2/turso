# 08. Transactions, WAL, Checkpoint, And Resumable I/O

目標：在第 02–04 章已存在的 `IOResult`、completion、pager/B-tree/VM state machine 上，忠實搬入 production transaction、savepoint、statement journal、WAL、shared WAL coordination 與 checkpoint。Turso 的主路徑是 WAL；不得先做一套「沒有 WAL 的同步 COMMIT」再重構，也不得把任何可能 yield 的步驟寫成從頭重跑。

共同背景：`learn/07a-wal-transactions-checkpoint.md`, `learn/07a-source-code-learn-wal-transactions.md`, `learn/07b-ioresult-reentry.md`, `learn/07b-source-code-learn-ioresult-reentry.md`, `docs/agent-guides/transaction-correctness.md`, `docs/agent-guides/async-io-model.md`。Target 一律保留 Source basis 的原相對路徑；completion 未完成時保存的 state 必須足以安全 re-enter。
