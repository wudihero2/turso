# 01. Runtime Values, Schema, And Records

目標：忠實重建 Turso 現有的 runtime value、immutable record codec 與 schema catalog。這些實作主要位於 `core/types.rs`, `core/storage/sqlite3_ondisk.rs`, `core/schema.rs`，不得重新分檔成 `value.rs`、`record.rs` 或「教學版 catalog」。Target 一律是 `learn-codebase/` 下的相同相對路徑。

本章共同背景是 `learn/05-schema-values-records.md`, `learn/05-source-code-learn-schema-values-records.md`, `learn/06a-source-code-learn-file-format-pages.md`。大檔依 symbol 群組逐步搬入；每個群組都要保留 allocator-aware fallible path、feature gate、錯誤型別與 inline tests。
