# 04. VDBE Bytecode VM

目標：忠實重建 `core/vdbe/*` 的 instruction model、program builder、runtime state、interpreter、ephemeral structures 與全部 opcode。不得另造 `vm/op_*.rs`、縮小 instruction enum，或先寫一個只跑手寫 bytecode 的 VM。Target 保留 production 相對路徑。

共同背景：`learn/04-vdbe-execution.md`, `learn/04-source-code-learn-1-insn-dispatch.md`, `learn/04-source-code-learn-2-cursor-opcodes.md`, `learn/04-source-code-learn-3-aggregate-sorter-subprogram.md`。`core/vdbe/execute.rs` 依 opcode family 分 task，但最後必須仍是一個相同檔案；每個 `Insn` variant 必須有原本的 execute function、vtable entry、explain row 與 readonly classification。
